# Código de Conduta

Baseado no [Contributor Covenant](https://www.contributor-covenant.org/), versão 2.1.

## O compromisso

Quem participa deste projeto (issue, PR, discussão, revisão) se compromete a fazer dele um lugar sem
assédio para todo mundo, qualquer que seja idade, corpo, deficiência, etnia, identidade ou expressão de
gênero, nível de experiência, escolaridade, situação econômica, nacionalidade, aparência, raça, religião
ou orientação sexual.

## O que se espera

- Tratar as pessoas com respeito, mesmo discordando.
- Dar e receber crítica sobre o código, não sobre a pessoa.
- Ter paciência com quem está começando.
- Assumir o erro, pedir desculpa e aprender com ele.

## O que não se aceita

- Ofensa, xingamento, piada ou comentário de cunho sexual, racista ou discriminatório.
- Ataque pessoal, provocação, perseguição.
- Publicar dado de outra pessoa (telefone, endereço, conta, conversa) sem autorização.
- Vender curso, serviço ou produto em issue e PR.
- Qualquer conduta que seria inadequada num ambiente profissional.

## Como avisar

Viu algo fora destas regras? Fale com o mantenedor pelo perfil MatheusSBPRO no GitHub ou use o botão de
denúncia do próprio GitHub no comentário. O aviso é tratado com sigilo.

## O que acontece

O mantenedor decide a medida conforme o caso: um aviso, a remoção do comentário, a suspensão temporária
ou o banimento do projeto.
